# Neural Bloom — bounded asset handoff

FRONTIER-02-A, three-player-20260911. Parent owns integration and final acceptance.

Implemented in `player-three-aurora.js`, preserving `createAuroraAsset(THREE)`. No imports, network, animation loop, renderer/camera mutation, player edits or storage access. This entirely replaces the old ribbon composition with a broad, genuinely three-dimensional neural canopy: braided trunk, exposed suspended roots, recursively branching fibre bundles, occasional long-range connections, cellular junctions and deep motes.

The factory returns the exact host Three Group, update, setPalette, idempotent dispose, diagnostics, and a view profile. The host places the group at y=2.75. The asset uses a local elapsed clock so returning to the scene or re-enabling movement does not jump to the host time. Motion off freezes audio brightness, electrical-front ages, per-band values, material phases and group rotation. Explicit intensity/palette/quality changes remain possible. Quality low reduces motes while retaining the principal structure.

Real audio mapping: each branch family samples one of the 64 supplied spectral bands; bass/mid add bounded canopy flexion; treble excites junction size; real `onset && active` creates an electrical front with supplied pulse strength. Eight retained fronts travel along the common root-to-branch coordinate. Silence and idle never manufacture onset events. Gentle ambient turning/breathing is intentionally separate from beat response.

Measured structure with actual local Three 0.185.1: 198 branches, 381 strands, 198 junctions, 1,050 motes (480 low), 77,616 triangles and 3 asset draws. Three geometries and three materials; no per-frame geometry mutation or per-frame arrays. Current expanded fibre bounds are min[-4.126,-3.258,-3.319], max[3.916,3.695,3.665]; cellular junctions also have .8 margins and deep motes have separate .6 margins. Stronger sound-driven shader flexion is included in those margins.

`check-neural.mjs` passes nine structural/behavioral checks: namespace and finite geometry/bounds, budgets, silence without false events, onset and spectrum routing, exact motion freeze, bounded inputs and phase continuity, all nine palettes, quality draw count, complete idempotent disposal. Run with the bundled Node runtime from project root. The initial draft test assumed at least400 strands; measured deterministic construction has381. Corrected the test's arbitrary floor to300 (brief requires no exact count) without changing scene complexity. Initial particle diagnostics returned Infinity before the first update; corrected by setting the initial draw range explicitly, then reran all checks.

This evidence does not establish shader compilation, appearance or performance in the real browser. Parent must inspect all three integrated worlds, including static initial pose, actual playing audio, motion off/on, palette transitions and camera fit. Pay particular attention to filament readability and bloom restraint at the current player viewport; any art adjustment should be based on that rendered evidence. No world-first, best-in-world or GPU performance claim is made.

## Sound-motion refinement after parent rendered review

Parent reported a clean, attractive violet/cyan tree with roots visible and appropriate framing, but macro motion was too subtle while an actual220Hz modulated test WAV played. Initial bend amplitudes only added .055/.046 times broad bass/mid means; those arithmetic averages dilute a narrow-band signal. The refinement preserves the entire geometry, view profile, static silhouette and budgets. It introduces a smoothed envelope based on the supplied64-band RMS together with bass and overall energy. Actual sound now opens the upper canopy by up to9% horizontally and14% in depth, with coherent rolling bends up to .18/.26 scene units and restrained sound-dependent depth drift. The root remains anchored. Idle has only quiet ambient movement. The envelope releases into silence and does not create events. True-onset fronts now have stronger localized filament glints and junction flashes; no global strobe.

All nine checks rerun successfully, with the existing audio test expanded to establish that a single audible spectral band generates a nonzero movement envelope despite tiny broad-band means, returns near zero in silence, and creates no false onset. Exact motion-off snapshots include both new animated uniforms and rotations. Parent must still inspect the updated motion and shader result in the actual browser; the earlier rendered acceptance covers the pre-refinement version.
