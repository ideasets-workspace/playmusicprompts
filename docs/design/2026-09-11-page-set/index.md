# PlayMusicPrompts — page designs

The approved Create homepage and four separate desktop design previews. All visible interface wording is English. Login, Explore, Radio and Library were generated individually using built-in ImageGen, then visually inspected. This is a visual design set; browser interactions, authentication and live music generation are not implemented or verified by these images.

Return to your account with Google, Amazon, Apple or email. Continue without an account remains available. The pictured player represents arriving during a listening session.
