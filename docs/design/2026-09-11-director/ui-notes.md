# Director UI integration notes

The supplied files are `player-three-director-ui.js` and `player-three-director.css`. Imports target the installed website's sibling modules exactly as the brief requires. No renderer, audio graph, storage adapter, animation loop, network access or packages are created by this UI. The parent owns the actual scene and applies configuration.

## Contract

`createDirectorControls({container,getConfig,commit,getSnapshot,getTrack,audio,getLive,captureFrame,toast,seek})` returns `{refresh,update,dispose}`. `commit` is synchronous and returns `{ok,config,error?}`; the parent must retain failed-write candidates as its current config. `getSnapshot` supplies the **effective** complete current settings and actual scene, including a running morph/score if applicable. `captureFrame` resolves after the actual renderer's PNG download is initiated and rejects with a readable error on failure. The UI reports a download request, not a verified file path. Optional `seek(time)` connects cue jumps to the existing player's intentional seek/session ownership; if omitted, the fallback assigns `audio.currentTime`.

Call `refresh()` after external configuration changes. Call `update(live)` at the parent's refresh cadence; it updates actual signal meters, pad position, playhead, current cue and readable engine status, with no writes or form reconstruction. Current config, audio, track and live signals are read from parent callbacks. Native media events also synchronize track/playback constraints. `dispose()` removes mounted DOM and registered event listeners; an in-progress capture cannot update the removed UI.

Mount inside the fourth Studio tab and keep the existing real scene preview above. This stylesheet is namespaced to `.director` and does not change the existing scene/player geometry. It includes compact two-column cue fields below560px and a one-column corner map below350px. Source-reviewed layout intent is not actual browser evidence.

## Connected actions

- **Perform:** Manual disables follow and all routes, retains route choices/depth and the underlying29 saved settings, and exits morph/score. Live morph enables four-corner interpolation. The pad uses pointer capture plus arrow keys, Shift for10% steps, Home/End for opposing corners, and separate native horizontal/vertical ranges. Direct pad/range input disables Follow music and preserves the other axis's current following position. Follow is explicitly enabled by its switch. Corner selects choose a built-in full look or capture the current effective scene look without silently enabling morph.
- **Routes:** Four keyed editable lanes expose an actual source, target, signed amount, enabled switch and real supplied source meter. A scene-specific target outside the current world is visibly dormant. The UI adds no automatic/demo meter signal. Enabling routes in manual mode is clearly labeled Signal Routing; the Manual button is the full bypass.
- **Score:** No track produces an accurate empty state and disables capture/arm. A score attached to another track disables capture, arming, cue edits and seeking; explicit clear/removal remains available. Capture reads current settings and scene, binds the actual track ID, and stores a chosen real second and transition. Native seek uses `audio.currentTime` without starting playback. Capture upserts the cue at an exact existing time while retaining its ID; editing an existing row to another cue's time is rejected visibly. Capture/time edits cannot exceed a known song duration.24 cues maximum, names48 characters, transitions0–30 seconds. Keyed rows retain focused form nodes. Audio-frame updates do not rebuild inputs. Clear only clears the score and returns to manual if score was active.
- **Lens:** Three0–1 optical controls, still/breathe/arc, depth and a scoped reset. The camera notice explains Motion and composed views. Frame capture awaits the real parent callback, disables duplicate capture while pending, and displays actual failures without a success claim. Reset restores zero optics/still with .35 depth without altering the29 appearance fields or audio.
